# Gear page photos

Drop your photos in this folder. The gear page looks for these filenames:

## Skates
- `riivo-carbon.jpg` (or `.png`, `.webp`)
- `edgetek-carbon.jpg`
- `fr1-325.jpg`

## Cycling
- `trek-domane.jpg`
- `cruzbike-vendetta.jpg`

## Protective gear
- `protective-gear.jpg`

## Clothing & accessories
- `skating-kit.jpg`

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

You can add or remove items by editing the `gearItems` list in `src/pages/gear.astro`.
